# Проектирование и настройка иерархической сети предприятия (L2)

Данный проект демонстрирует навыки проектирования отказоустойчивой и безопасной локальной сети для офиса банка, разделенного на два этажа.

## 🏗️ Топология сети
Сеть построена на базе коммутаторов **Cisco Catalyst 2960**. 
Использована двухуровневая модель с разделением на логические сегменты (VLAN).

### Реализованные технологии:
* **VLAN (Virtual LAN):** Логическая сегментация сети на отделы.
  * `VLAN 10` — Бухгалтерия (BUH)
  * `VLAN 20` — Касса (KASSA)
* **802.1Q Trunking:** Настройка магистральных каналов между этажами для передачи трафика нескольких VLAN по одному физическому линку.
* **Network Security:** * Защита привилегированного режима (Secret password).
  * Настройка удаленного доступа по протоколу **SSH** (RSA 1024 bit) с локальной базой пользователей.
* **STP (Spanning Tree Protocol):** Обеспечение защиты от петлевых соединений и расчет путей передачи данных.

## 💻 Используемое оборудование
* Коммутаторы: 2 x Cisco WS-C2960-24TT
* Конечные устройства: 4 x PC (Windows)
* Среда моделирования: Cisco Packet Tracer

## 🚀 Как запустить проект
1. Скачайте файл проекта `Bank_Network.pkt`.
2. Откройте его в **Cisco Packet Tracer 8.2** или выше.
3. Убедитесь, что пинги между хостами в одном VLAN проходят успешно, а между разными VLAN — блокируются (согласно политике безопасности).
